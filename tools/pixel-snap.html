What this is. The "clean AI output into true pixel art" stage that runs after the model. Pipeline, all client-side: fit-and-downsample to the target grid → median-cut quantize to N colors → flood-fill the background from the four corners within a color tolerance (so interior details of the same color are preserved) → nearest-neighbor upscale for preview. The generation-complete "reconstruction" shimmer is a cosmetic canvas reveal (diagonal sweep + per-pixel fade), not part of the model.
Note. The corner-key handles the common transparent-on-flat-background case; some models return native alpha instead. Algorithm is original (MIT-spirit).
